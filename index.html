如何產生及匯出瀏覽器書籤

① 保存開啟分頁成書籤

將目前視窗的所有分頁存入新資料夾（多個視窗請分別執行）：

WindowsCtrl + Shift + D
Mac⌘ + Shift + D
※ 亦可在分頁標籤按右鍵選「將所有分頁加入書籤」

② Chrome 匯出 HTML

開啟書籤管理員快捷鍵：

WindowsCtrl + Shift + O
Mac⌘ + ⌥ + B
chrome://bookmarks/

從管理器匯出：點擊右上角「⋮」（整理選單）→「匯出書籤」→ 存為 HTML 檔案。

③ Edge 匯出 HTML

開啟我的最愛管理員快捷鍵：

WindowsCtrl + Shift + O
Mac⌘ + ⌥ + B
edge://favorites/

從管理器匯出：點擊右上角「⋯」（更多選項）→「匯出我的最愛」→ 存為 HTML 檔案。

④ Firefox / Safari 匯出

Firefox 開啟收藏庫：

Win / MacCtrl / ⌘ + Shift + O

點上方「匯入及備份」→「匯出書籤成 HTML」。

Safari (Mac)：上方選單列點「檔案」→「匯出書籤...」即存為 HTML。

⑤ 匯入 NotebookLM

將精選書籤匯入 NotebookLM 建立 AI 知識庫：

單一筆記本建議≤ 50 個來源

操作方式：篩選目標資料夾 → 點擊「✨ NotebookLM」複製 → 到 NotebookLM 點「新增來源」貼上文字！

📁 匯出的檔案存在哪裡？ 瀏覽器匯出的書籤 HTML 檔案預設保存在電腦的「下載」資料夾（Mac：~/Downloads、Windows：下載 (Downloads)）；若有跳出另存新檔視窗，則會儲存至您指定的資料夾。
